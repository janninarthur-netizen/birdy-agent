# Birdy Agent · Le golf sur mesure

**Site : [birdy-agent.pages.dev](https://birdy-agent.pages.dev/)**

Birdy Agent est un service de golf en France, avec Birdy, un assistant qui répond tout de suite :

- [Réserver un parcours](https://birdy-agent.pages.dev/parcours/) : 621 golfs de France, avec les tarifs publics de green fee quand le golf les publie.
- [Voyages golf](https://birdy-agent.pages.dev/voyages/) : séjours de groupe dans 55 destinations, entre amis, en EVG ou en séminaire.
- [Débuter le golf](https://birdy-agent.pages.dev/debuter/) : les bases, le matériel, l'étiquette et le lexique, en 3D.
- [Cours avec un pro](https://birdy-agent.pages.dev/cours/) : initiation, cours, stages, partout en France.

Les demandes sont gratuites et sans engagement : un conseiller confirme l'horaire et le prix avant toute réservation.
